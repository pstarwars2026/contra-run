# ContraRun

A browser-based 2.5D run-and-gun game built with Three.js.

## Play

Open `index.html` in a modern browser.

Controls:

- Move: Arrow keys or WASD
- Fire: Z / J / Control
- Jump: X / K / Space
- Dash: Shift / C
- Pause: P
- Mute: M

## Development

```bash
npm install
npm test
```

`main` contains the stable v1 release. New visual and Blender/Three.js experiments are developed on the `v2` branch.
